# **Система компьютерного зрения для распознавания символов армянского алфавита с БПЛА.**
Выполняется в рамках студенческого конкурса авиационного творчества (СКАТ). Задание:
```
Поиск при помощи систем Компьютерного зрения:
распознавание чёрных символов (армянский алфавит) на белом полотне в виде
квадрата размером 3 ✕ 3 м. Символы, которые потребуется распознавать,
приведены на рисунке 1. Задача: распознать символ (назвать букву Оргкомитету),
а также зафиксировать координату нахождения символа с точностью до 10
(десяти) метров от его центра. Распознавание символов необходимо производить
непосредственно на борту БВС. Сразу после посадки необходимо предоставить
представителям Оргкомитета карту MicroSD с файловой системой FAT32 и
файлом objects-coordinates.csv, в котором данные об обнаруженных объектах
записаны построчно в формате: <идентификатор объекта> (номер буквы начиная
с 0), <широта*1e7>, <долгота*1e7> широта и
долгота в системе WGS84. Нумерация идёт слева направо, сверху вниз.
```
Программа разворачивается на Raspberry Pi 5, с камерой C/CS IMX477R 12.3 Mp и объективом CS2316ZM02 16mm.

## Описание работы
Для обучения была выбрана модель Ultralytics YOLOv8n. Обучалась она сначала на синтетических данных (из папок ```arm_alph``` и ```backgrounds```), позже на конкретно нашу камеру были отсняты все буквы и разные травяные и земляные фоны. Стоит отметить, что в папках представлены лишь примеры букв и фонов, на деле было около 10-15 разных снимков на каждую из букв, каждый из которых в дальнейшем проходил аугментацию (небольшие растяжения, обрезка, изменение оттенка цвета и яркости). Генерация датасета представлена в файле ```generate_dataset```. 

Обученная модель ```best.pt``` загружалась на Raspberry. В файле ```predict_on_uav.py``` объединены все основные процессы, происходящие на борту. Идет запись видео, детекция букв в реальном времени (2-5 FPS), сохранение в файл, подсчет WGS84 координат буквы.

Для получения телеметрии с полётного контроллера по протоколу MAVlink используется файл ```mavlink_reader.py```. 

Файлы с расширением ```.service``` должны быть помещены в папку ```etc/systemd/system```, они обеспечивают автоматический запуск всех программ при включении компьютера и перезапуск скриптов при ошибках.
